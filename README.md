# CodeAlpha_EcommerceStore
CodeAlpha Task 1: Full Stack E-commerce Web Application featuring user authentication, dynamic product catalog, interactive shopping cart, and complete order processing workflows. Developed with HTML, CSS, JavaScript, and a robust backend API.
## 🚀 Features
* **User Authentication:** Secure user registration and login system[cite: 2].
* **Product Catalog:** Dynamic product listings and dedicated product detail pages[cite: 1, 2].
* **Shopping Cart:** Add, remove, and manage items seamlessly.
* **Order Processing:** Complete checkout flow that saves order details to the database[cite: 1, 2].

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node, Express.js
* **Database:** SQLite / MongoDB
